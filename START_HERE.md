# Netlify trial

Read README.md for Netlify deployment and Windows local setup. Use this edition for Netlify, rather than the earlier Sites/Cloudflare ZIP.

Project root: the folder containing package.json and netlify.toml.
Netlify build: npm run build
Publish directory: .next
Runtime variable: VOLTB_STORAGE=netlify (builds and functions)
Admin setup: ADMIN_EMAIL, ADMIN_PASSWORD (12+ characters), ADMIN_SESSION_SECRET (32+ random characters)

This is a test store: payment and courier services remain disabled.
